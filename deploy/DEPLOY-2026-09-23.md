## Nova ovisnost — `npm install` je OBAVEZAN

`travelo-transactions-service` je dobio `xml2js` (gradi UBL/temeljnicu u XML-u).
Bez instalacije servis se nece podici.

```bash
ssh deploy@46.101.176.117
cd ~/opt/TraveloApp        # radna kopija je /root/opt/TraveloApp

git pull
( cd travelo-transactions-service && npm install )

bash deploy/spa_build.sh   # portal je mijenjan (izbor SAOP sifri, gumbi po uredaju)
pm2 restart all --update-env
```

Migracija u ovom izdanju nema.

## Sto provjeriti

```bash
# Sifarnici iz SAOP-a kroz backoffice (mjesta troska / nositelji / referenti).
curl -s "localhost:7010/seyfor_codebook?kind=cost_units" | head -c 200

# Dnevna realizacija — temeljnica mora biti uravnotezena (duguje = potrazuje).
curl -s "localhost:7030/daily_realization?from=2026-09-23&to=2026-09-23" | head -c 300
```

Slanje u SAOP ne treba pokretati na VM-u da bi se izdanje smatralo ispravnim —
knjizenje ide prema stvarnom iCenteru, pa ostaje na dogovor s uredom.
