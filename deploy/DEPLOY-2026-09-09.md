## Brojaci na bookings (rucni korak, jednom)

Booking servis od ovog izdanja vodi tri nova stupca na `bookings`:
`validated`, `validated_other` i `validated_out`. Prva dva su vec postojala u
modelu, treci je nov — ako ih baza nema, dodaju se:

```sql
ALTER TABLE bookings ADD COLUMN IF NOT EXISTS validated integer DEFAULT 0;
ALTER TABLE bookings ADD COLUMN IF NOT EXISTS validated_other integer DEFAULT 0;
ALTER TABLE bookings ADD COLUMN IF NOT EXISTS validated_out integer DEFAULT 0;
```

Brojaci se pune tek novim ocitanjima, pa kapetanski modul za ranije validirane
karte pokazuje nulu. Test baza je vec napunjena skriptom koja svaku kartu sa
`status='validated'` javi na `POST /bookings/validate`; za drugu instalaciju
isti postupak vrijedi i ondje. Bez toga brojke nisu netocne, samo nepotpune —
popunit ce se same kroz nekoliko polazaka.

## Mobilna 1.0.9

APK se **ne objavljuje u portalu**. Mobilnu blagajnu instalira podrska izravno
na uredaj, pa datoteka ne stoji u `downloads/` — ondje bi je mogao preuzeti
svatko tko ima pristup portalu.

```
travelo-mobile/android/app/build/outputs/apk/release/travelo_app-v1.0.9.apk
```

Instalacija preko postojece verzije zadrzava uparivanje i lokalne podatke:
`adb install -r travelo_app-v1.0.9.apk`. Ako javi
`INSTALL_FAILED_UPDATE_INCOMPATIBLE`, aplikacija je na uredaju potpisana drugim
kljucem — tada deinstalacija pa instalacija (uparivanje se radi iznova).

## Upute i preuzimanja

PDF-ovi, instalacijski paket i `downloads.json` nisu u gitu (mapa je
gitignorana), pa se prenose rucno:

```bash
scp "travelo-boat-desk/dist/Travelo Boat Desk Setup 1.0.25.exe" \
    "travelo-boat-desk/docs/upute/TraveloAPP-Boat-Desk-upute-za-blagajnika-1.0.25.pdf" \
    "travelo-mobile/docs/TraveloAPP-upute-za-operatera-1.0.9.pdf" \
    deploy@46.101.176.117:~/TraveloApp/travelo-web_portal-service/downloads/
```

Na VM-u zatim:

1. u `downloads.json` podici brojeve na 1.0.25 (desk + upute za blagajnika) i
   1.0.9 (upute za operatera) — imena datoteka nose verziju, pa se mijenjaju i
   `file`, `title` i `version`,
2. stare datoteke (1.0.24, 1.0.8) i eventualni APK premjestiti u
   `downloads_archive/`,
3. `pm2 restart travelo-web_portal-service`.

## Provjera nakon deploya

- Plovidba → kapetanski modul, polazak s validiranim kartama: „Na brodu" mora
  biti zbroj validiranih i onih s drugih polazaka, „Iskrcava se" broj putnika
  koji izlaze u toj luci.
- Financije → Pregled karata → otvaranje jedne karte.
- Kontrola: ponovljena ocitanja i stornirane karte moraju se pojaviti u
  sukobima.
- Mobilna: Validacija → PREGLED pokazuje samo karte odabrane ulazne luke,
  POVIJEST ocitanja tog polaska.
