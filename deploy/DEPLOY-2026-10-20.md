## YesCor 401 na VM-u

Web prodaja od 7.10. ne salje F2 racune: YesCor vraca
`401 unauthorized_client — Invalid client or Invalid client credentials`.
Lokalni kljucevi istog klijenta (`hr_32137068117_3e970`) dobivaju token, pa je
kriva vrijednost u okolini VM-a.

```bash
env | grep ^YESCOR_ | sed 's/=.*/=<set>/'     # koje su postavljene
```

Ispravi `YESCOR_CLIENT_SECRET` (i `YESCOR_CLIENT_ID` ako je postavljen) u
`~/.profile`, pa restart redom — control prvi, jer on dijeli konfiguraciju:

```bash
source ~/.profile
pm2 restart travelo-control-service --update-env
pm2 restart travelo-transactions-service --update-env
```

Provjera: sljedeci F2 racun iz web prodaje ne smije se pojaviti u
Kontrola → F2 greske s porukom `token endpoint failed`.
