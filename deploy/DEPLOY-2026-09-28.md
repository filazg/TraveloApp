### 4. Provjera

```bash
curl -s "http://127.0.0.1:7030/ticket_stornos" | head -c 300; echo
curl -s -X POST http://127.0.0.1:6020/terminal/storno_check \
  -H 'Content-Type: application/json' -d '{"ticket_uuids":["provjera"]}'; echo
curl -s -X POST http://127.0.0.1:6020/terminal/storno_attempt \
  -H 'Content-Type: application/json' -d '{"attempts":[]}'; echo
curl -s "http://127.0.0.1:6010/transactions/ticket_stornos" | head -c 200; echo
```

Ocekivano redom: `{"status":200,"data":{"stornos":[...` · `"allowed":true` ·
`"attempts required"` (400 — ruta postoji) · `"path2":"ticketStornos"`.

Portal: Kontrola → plocica „Storniranje".
