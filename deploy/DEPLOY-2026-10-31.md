### 1. Dohvat i ovisnosti

```bash

```

### 2. Restart backend servisa

```bash
pm2 restart travelo-backoffice-service travelo-boat-service travelo-transactions-service \
            travelo-web_portal-service travelo-web-sales-service --update-env
```

### 3. SPA build i pokretanje

```bash
(cd travelo-portal && npm run build)
(cd travelo-web-sales-v2 && npm run build)
SPA_MODE=preview pm2 restart ecosystem.config.js --only travelo-portal --update-env
SPA_MODE=preview pm2 start ecosystem.config.js --only travelo-web-sales-v2 --update-env
pm2 save
```

`travelo-web-sales-v2` sluša na `127.0.0.1:5177` s osnovnom putanjom `/v2/`.
