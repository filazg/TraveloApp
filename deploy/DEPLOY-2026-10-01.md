## Koraci

```bash
ssh deploy@46.101.176.117
cd ~/opt/TraveloApp        # radna kopija je /root/opt/TraveloApp
```

### 1. Dohvat

```bash
git pull
```

Nema novih ovisnosti — `npm install` nije potreban. Control se ne dira.

### 2. Migracije (preskoci ako je baza zajednicka s lokalnom)

```bash
node travelo-boat-service/migrate_seop_right_discounts.js     # ticket_type_uuid/_name na popustima
node travelo-boat-service/migrate_ticket_type_extras.js       # tickets_types.extra_tickets
node travelo-transactions-service/migrate_ticket_extras.js    # tickets.is_extra, extra_of_ticket_uuid
node travelo-auth-service/migrate_partner_api_logs_bodies.js  # request/response u logu API partnera
```

Tablica `partner_api_logs` i kategorija `BEZ_KAPACITETA` nastaju same pri
pokretanju auth odnosno booking servisa.

### 3. Restart

Backoffice mora biti gore prije autha (auth pri startu sinkronizira partnere).

```bash
pm2 restart travelo-booking-service travelo-boat-service travelo-akd-service travelo-transactions-service
pm2 restart travelo-auth-service
pm2 restart travelo-channel-terminals-service travelo-channel-api-service travelo-web_portal-service
```

### 4. Portal (SPA)

```bash
cd travelo-portal && npm run build && cd ..
SPA_MODE=preview pm2 restart ecosystem.config.js --only travelo-portal --update-env
```

NE `pm2 restart ecosystem.config.js` bez `--only` — restarta i control.
